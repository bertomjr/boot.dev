# Boot.dev

My programming projects built while following [Boot.dev's Backend Developer Path (Python & TypeScript)](https://www.boot.dev/paths/backend?tech=python-typescript).

I'm using these projects to strengthen my programming fundamentals and build toward backend development. The current projects use Python, with a focus on command-line programs and object-oriented programming.

## Projects

This collection will grow as I complete more guided and independent projects.

| Project | Description | Learning focus | Origin |
| --- | --- | --- | --- |
| [Bookbot](./Bookbot/) | A command-line program for analyzing text files and reporting word and character counts. | File handling, functions, dictionaries, and text processing | [Boot.dev guided project](https://www.boot.dev/courses/build-bookbot-python) |
| [Asteroid Game](./Asteroid%20Game/) | A Python recreation of the classic Asteroids game. | Object-oriented programming, game loops, user input, and collision detection | [Boot.dev guided project](https://www.boot.dev/courses/build-asteroids-python) |

## What I'm practicing

- Turning project requirements into working programs.
- Breaking problems into smaller functions, classes, and modules.
- Choosing data structures that fit the problem.
- Debugging program behavior and refining my implementations.
- Using Git and the command line throughout development.

These projects document my progress as a developer. I will revisit earlier work as I learn better ways to solve problems.

## Explore locally

Clone the collection:

```bash
git clone https://github.com/bertomjr/boot.dev.git
cd boot.dev
```

Then open the folder for the project you want to explore:

```bash
# Bookbot
cd Bookbot
```

Or, from the repository root:

```bash
# Asteroid Game
cd "Asteroid Game"
```

Each project is a standalone program with its own setup requirements. Install its dependencies and run its code from that project's directory.
